# C++ Expense Tracker

A command-line expense tracker built with C++20.

## Features

- Add expenses with descriptions, categories, and amounts
- View recorded expenses
- Calculate total spending in EUR
- Save expenses to a CSV file
- Load saved expenses when the application starts

## Technologies

- C++20
- GCC
- Git

## Build

Compile the application using GCC:

    g++ -std=c++20 -Wall -Wextra -Wpedantic src/main.cpp -o expense-tracker.exe

## Run

Run the executable in PowerShell:

    .\expense-tracker.exe

The application stores expenses in expenses.csv.
